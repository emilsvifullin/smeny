# Audit closure — Shift Register 6.0.0

Статус: пакет исправлений High / Medium / Low применён к версии 6.0.0.

## Закрытые направления

- единый production-список из 14 ПВЗ со стабильными ID;
- строгая схема данных v3 и единая валидация при обычной загрузке и импорте;
- исторический snapshot тарифа для каждой смены;
- пустой ШК остаётся допустимым;
- безопасная работа с будущими сменами и авансом;
- лимиты и safe-integer проверки денежных/числовых полей;
- versioned JSON backup с revision и metadata;
- fail-closed при повреждённом хранилище;
- last-good recovery и сохранение raw повреждённой копии;
- обнаружение конфликтов параллельной записи по revision;
- BroadcastChannel для межвкладочного уведомления;
- детерминированное локальное хранилище без недоказанного cloud-sync слоя;
- безопасный service-worker update lifecycle без принудительного reload во время редактирования;
- network timeout и корректный offline cache;
- улучшения keyboard/focus/dialog semantics, zoom, hit areas и контраста;
- разделение config / domain / storage / UI / styles;
- CSP и отсутствие внешних runtime-зависимостей;
- тесты и GitHub Actions CI;
- README / changelog / release documentation.

## Что остаётся вне автоматической проверки архива

Физическая финальная проверка поведения после публикации на GitHub Pages на реальном iPhone/PWA зависит от браузера и хостинга. После загрузки архива рекомендуется открыть опубликованный URL, создать тестовую смену, перезагрузить страницу и один раз проверить offline launch. Код и статические проверки для этих сценариев включены в пакет.
