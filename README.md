# Shift Register

Небольшое PWA для учёта смен и предварительного расчёта выплат сотрудников ПВЗ.

## Запуск

Приложение статическое. Для локальной проверки запустите HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Проверки

Требуется Node.js 20+:

```bash
npm test
npm run check
```

CI запускает те же проверки в GitHub Actions.

## Данные

- Активный производственный список содержит ровно 14 ПВЗ.
- Пустой ШК допустим.
- Данные хранятся локально на устройстве; перенос между устройствами выполняется JSON-резервной копией.
- Перед заменой или удалением базы сохраняется предыдущая исправная версия.
- Смена хранит снимок применённых тарифных правил, поэтому последующие изменения тарифов не должны менять уже сохранённые расчёты.
- Будущие смены можно внести заранее, но до наступления даты они не входят в фактически начисленные суммы.
- Неполная смена округляется до целого рубля отдельно по каждой смене.

## Резервные копии

Экспорт формирует versioned JSON envelope с версией схемы, приложения, правил и ревизией. Импорт проходит строгую валидацию; неизвестные ПВЗ и неподдерживаемые версии отклоняются, а не угадываются.
