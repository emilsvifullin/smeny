# Changelog

## 6.0.0 — 2026-08-07

- Зафиксирован производственный список из 14 ПВЗ.
- Добавлены стабильные идентификаторы ПВЗ.
- Введена схема данных v3 и снимок тарифа для каждой смены.
- Ужесточены валидация, импорт и миграции.
- Ошибки чтения больше не превращаются в пустую базу.
- Добавлены ревизии, обнаружение конфликтов, read-back verification и last-good backup.
- Удалена недоказанная cloud-синхронизация; режим хранения теперь честно отражает local/memory.
- Черновик и UI-состояние изолированы в sessionStorage.
- Будущие смены исключены из начислений до наступления даты.
- Улучшены PWA update/offline стратегии.
- Улучшены keyboard/accessibility semantics и focus management.
- Убраны принудительный zoom lock, document.write и глобальный запрет выделения текста.
- Добавлены CSP, ограничения размеров данных, тесты и GitHub Actions CI.
- Проект разделён на config/domain/storage/app/styles вместо одного монолитного HTML.
